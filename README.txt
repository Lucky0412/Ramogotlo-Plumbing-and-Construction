RAMOGOTLO PLUMBING & CONSTRUCTION WEBSITE

Included:
- Responsive one-page website (HTML/CSS/JavaScript)
- Company logo extracted from the supplied logo image
- Hero and service images cropped from the supplied website inspiration screenshot
- Mobile navigation menu
- Quote enquiry form (mailto-based; no backend)

HOW TO RUN:
1. Extract the ZIP folder.
2. Open index.html in a web browser, or open the folder in Visual Studio Code.
3. For development, install the VS Code Live Server extension and choose "Open with Live Server" on index.html.

BEFORE PUBLISHING:
- Open script.js and replace COMPANY_EMAIL = 'replace-with-company-email@example.com' with the company's actual email.
- Update any company phone/address details when they are confirmed (not provided yet).
- The quote form opens the visitor's email application. It does not save submissions to a database or send automatically.
- To have online form submissions saved or emailed automatically, connect a backend or form service.
